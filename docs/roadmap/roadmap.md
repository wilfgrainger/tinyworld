# Product roadmap

The roadmap is dependency-gated, not a promise of dates. A release advances only when its acceptance record distinguishes local evidence from Studio, multi-client, published-place, and device evidence.

| Release | Purpose | Gate |
| --- | --- | --- |
| v0.5.1 | Physical-world hardening and save triggers | Historical baseline preserved |
| v0.5.2 | Village soul and presentation reset | Active implementation and acceptance |
| v0.6.0 | Fair cosmetic economy | Desirability, safety, persistence, and free-play parity evidenced |
| Later | More villages, worlds, homes, social systems, and live operations | Separate approved designs and measured need |

## Current release

[v0.5.2 Village Soul](v0.5.2-village-soul.md) is a presentation and world-content reset on the existing server-authoritative profile version 10 baseline. It prioritizes a compact HUD, a deterministic sixteen-home village, authored prefab boundaries, recognizable affordances, a hero starter home, and bounded ambient life.

## Deferred work

v0.5.2 does not add a new economy, paid gate, combat, profile migration, unrestricted procedural generation, or multi-village membership. Those decisions require their own evidence and approved designs.
