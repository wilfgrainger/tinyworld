# Village

## Scale and membership

One village displays at most sixteen resident homes, regardless of Roblox server capacity. Players beyond that visual cap are visitors until a future multi-village membership design is approved. Server capacity must never silently increase visible residential scale.

## Composition

The centre holds Town Hall, fountain, Village Shop, Home Store, Courier Depot, Transport Workshop, market, and portal landmarks. Each destination needs a distinct physical silhouette and keeps its existing server-owned interaction contract.

Residential plots are divided evenly across four seeded neighbourhoods:

| Neighbourhood | Identity | Homes |
| --- | --- | ---: |
| Meadow Lane | Gardens, stream, bridge, meadow planting | 4 |
| Harbour Row | Descending paths, dock views, boats, fishing clutter | 4 |
| Woodland Rise | Tree canopy, rocks, fireflies, narrower paths | 4 |
| Orchard End | Orchard trees, vegetable beds, nursery green | 4 |

## Layout rules

- Placement is deterministic and uses the fixed release art seed.
- Plot slots have explicit neighbourhood, rotation, and setback data.
- Stable ground and plot bases remain the collision foundation.
- Dressing uses bounded variants for trees, fences, flowers, lights, benches, rocks, and setbacks.
- Plots do not overlap, paths remain traversable, and civic landmarks stay visually discoverable.

## Existing gameplay contracts

Village presentation does not take authority from progression, contributions, professions, plots, privacy, visits, trades, transport, portals, or saves. World builders return named prompt anchors; services validate and execute the action.
