This is a craft gate, not monetisation or another gameplay system.

## Evidence rule

Local source and pure-test evidence, one-player Studio, two-client Studio, published-place, and mobile/controller evidence are separate. None substitutes for another, and an unchecked human gate is never implied to pass.

Historical release documents and dated records remain in place. The `docs/superpowers/` authority label in the canonical index remains controlling: those files are historical context unless an active release document explicitly links them as implementation input.
