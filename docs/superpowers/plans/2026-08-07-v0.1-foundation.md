# TinyWorld v0.1 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the smallest playable TinyWorld progression foundation: persistent profiles, universal level/XP progression, and five server-authoritative house tiers.

**Architecture:** Pure deterministic game rules live under `src/shared` so they are independently testable. Roblox-specific state, DataStore access, and the temporary Studio demo prompt live under `src/server`. Rojo maps those directories into standard Roblox services.

**Tech Stack:** Roblox Studio, Luau, Rojo project mapping, Roblox DataStoreService.

## Global Constraints

- Coins, XP, level, and house upgrades are server-authoritative.
- v0.1 contains exactly five house tiers: Starter Nook, Cosy Cottage, Family Home, Garden House, Grand Villa.
- Robux does not buy raw progression power in this slice.
- Data is versioned from schema version 1.
- Missing a feature from the wider design is not a reason to add it to v0.1.

---

## File structure

- `default.project.json`: Rojo mapping for shared/server/client source.
- `AGENTS.md`: contribution rules for coding agents.
- `src/shared/ProfileSchema.luau`: default profile and defensive profile normalisation.
- `src/shared/Progression.luau`: XP threshold and level-up rules.
- `src/shared/HouseCatalog.luau`: five house tier definitions.
- `src/shared/HouseUpgrade.luau`: pure validation/application logic for upgrades.
- `src/server/ProfileStore.luau`: DataStore adapter and in-memory profile ownership.
- `src/server/Main.server.luau`: player lifecycle, leaderstats, and temporary upgrade prompt.
- `src/client/Main.client.luau`: client bootstrap placeholder with no authority.
- `tests/TestUtil.luau`: tiny assertion helpers.
- `tests/ProfileSchema.spec.luau`: schema tests.
- `tests/Progression.spec.luau`: XP/level tests.
- `tests/HouseUpgrade.spec.luau`: house-rule tests.
- `tests/run.luau`: CLI test entry point.
