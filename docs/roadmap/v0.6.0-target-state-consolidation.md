# v0.6.0 Target-State Consolidation

**Status:** merged historical release on 10 August 2026; superseded as active delivery authority by v0.6.1 Visual Rescue.  
**Purpose:** apply the complete repository-side Target-State Upgrade Blueprint in one release/PR.

## Historical scope reconciliation

The canonical v1 target-state release train originally named v0.6.0 **Home Life Foundation** because home life was the primary player-visible product outcome of that release. On 9 August 2026 the repository owner explicitly approved implementing the **entire repository-side Target-State Upgrade Blueprint as one v0.6.0 PR**. Therefore the delivered scope became **v0.6.0 Target-State Consolidation**, with Home Life Foundation nested inside it as the principal player-facing slice rather than a competing release definition.

That decision superseded the older v0.5.x roadmap assignment that had deferred a Fair Cosmetic Economy slice to v0.6.0. Cosmetic expression remained no-pay-to-win and was included only as part of the broader character/home expression foundation.

This file records the v0.6.0 decision as history. It no longer defines current implementation sequencing. Current authority is `docs/releases/v0.6.1/acceptance.md` plus `docs/roadmap/v0.6.1-visual-rescue.md`; `docs/product/target-state-v1.md` remains authoritative for the long-term product destination.

## Visual lesson carried into v0.6.1

The first observed merged v0.6.0 screenshots showed that repository-side visual contracts and semantic prefab metadata were insufficient proof of rendered quality. Primitive character fallback geometry, floating information walls and overly dominant HUD chrome survived despite the written labels-off/premium-feel intent.

v0.6.1 exists to correct that presentation and strengthen the release process so required player-facing visual evidence blocks merge-ready status.

This observation does not retroactively change what v0.6.0 source/CI proved.

## Deliberately not fabricated

The release did not commit:

- Roblox credentials;
- fake universe/place/product/asset IDs;
- automated LIVE publishing;
- false Studio/device evidence.

DEV/LIVE publishing remained a separately approved human-gated configuration phase.
