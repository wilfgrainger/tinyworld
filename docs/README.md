# TinyWorld documentation

This index is the canonical entrypoint for TinyWorld product, engineering, quality, roadmap and release documentation.

## Documentation authority

Read/resolve conflicts in this order:

1. **Current release acceptance:** [v0.6.2 Village Life & Visual Craft acceptance](releases/v0.6.2/acceptance.md) defines what the release must prove and keeps automated evidence separate from Studio/device evidence.
2. **Target-state product contract:** [TinyWorld v1 Target State](product/target-state-v1.md) defines the product north star, launch content floor and v1 non-negotiables.
3. **Durable product/engineering/quality contracts:** the documents indexed below define ongoing rules and boundaries.
4. **Active release roadmap/spec/plan:** [v0.6.2 roadmap](roadmap/v0.6.2-village-life-visual-craft.md), [design](superpowers/specs/2026-08-10-tinyworld-v0.6.2-village-life-visual-craft-design.md) and [implementation plan](superpowers/plans/2026-08-10-tinyworld-v0.6.2-village-life-visual-craft.md) define current scope and sequencing.
5. **Historical records:** v0.6.1 and earlier release/spec/plan material remains useful evidence/decision history but does not override current authority.

A roadmap/spec never proves a feature shipped. CI never proves visual quality. Player-facing Studio/device evidence is required for player-facing visual acceptance.

## Current visual direction

TinyWorld aims for **Brookhaven-level readability + Toca-style tactile warmth + Ready Player One-style wonder**, expressed as original TinyWorld design rather than copied IP.

Current hard rules include:

- no primitive Part hair/shoe fallback;
- no primitive Part-built ambient creatures masquerading as finished characters;
- no large always-on-top ordinary-world information walls;
- no telemetry/dashboard language dominating normal play;
- labels and metadata supplement but do not rescue weak physical objects;
- hero objects have a higher craft bar than background fallback scenery;
- production assets require provenance/approval;
- observed visual evidence is a release gate.
