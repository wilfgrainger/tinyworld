# TinyWorld v0.0.5 Cosmetic Test

**Status:** Source route for the v0.0.5 storybook village candidate
**Scope:** Cosmetic presentation and gameplay regression only

This route preserves the original v0.01–v0.0.4 gameplay instructions. It adds evidence for the v0.0.5 visual contract.

## Before pressing Play

1. From the repository root, run \`rojo serve\` using the project’s installed Rokit/Rojo setup.
2. In Roblox Studio, connect the Rojo plugin to \`localhost:34872\).
3. Confirm the synced trees are present under \`ReplicatedStorage.TinyWorld.Shared\`, \`ServerScriptService.TinyWorld\`, and \`StarterPlayer.StarterPlayerScripts.TinyWorld\`.
4. Record the current Git SHA and keep the Output pane visible.
5. Confirm the published Dev place has Studio Access to API Services enabled.

## Visual route

Capture a screenshot at each checkpoint:

1. Spawn facing the fountain and the central square.
2. Walk the route from fountain to Town Hall, Courier Depot, Village Shop, Transport, Trading Post, and Portal.
3. Walk to an available plot and inspect the gate, fence, mailbox/owner sign, garden trellis, house façade, windows, shutters, roof trim, and garden beds.
4. Walk to the Woodland Trail, Cliff Lookout, and Sea Dock.
5. Enter the Giant Kitchen and inspect the portal frame and arrival platform.
6. View the HUD at the spawn viewport and while standing near a prompt.

The intended read is a small storybook diorama: warm layered façades, clear destinations, inviting plots, a deliberate outer frame, and restrained magical accents.

## Regression route

Run the existing gameplay path without changing any source in Studio:

- Complete onboarding or enter with an existing saved profile.
- Claim the daily fountain reward and confirm a second same-day claim is refused.
- Plant, water, and harvest a carrot.
- Take and deliver a Courier parcel.
- Buy, mount, and park the Tiny Bike.
- Cycle plot privacy and inspect the home upgrade prompt.
- Collect one living-world pickup and inspect the home/life-kit HUD.
- Visit boundary landmarks and claim the daily Boundary Explorer reward.
- Enter and finish the Giant Kitchen route.
- Use the Trading Post with two clients when available.
- Stop and rejoin to verify the existing profile values persist.

## Cosmetic acceptance checks

- No red runtime errors in Output.
- No grass, plot-border, or new decoration flicker while moving.
- No decorative part blocks a road, spawn, garden bed, kiosk, landmark, or prompt.
- Existing prompt names, action text, rewards, and route positions still work.
- The HUD remains readable at the normal Studio viewport and does not hide the player’s immediate route.
- The generated world remains bounded by the layout visual budget attributes.
- The visual pass does not add profile fields or alter reward/progression results.
