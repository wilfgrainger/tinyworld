# v0.5.2 Village Soul

## Goal

Make TinyWorld read as a warm, recognizable Roblox life game during ordinary play while preserving all v0.5.1 server-authoritative gameplay and persistence contracts.

## Delivery slices

1. Establish shared visual-quality contracts, fail-closed source checks, and canonical documentation.
2. Cap and compose a deterministic sixteen-home, four-neighbourhood layout.
3. Add authored civic, market, and plot-affordance prefab boundaries.
4. Replace the telemetry dashboard with compact HUD, journal, toasts, and visual onboarding.
5. Build the starter/Cosy hero home and improve vehicles and touched objects.
6. Add bounded ambient life and reconcile release evidence.

Each slice must add a failing behavior test or source guard before implementation and preserve service-facing return shapes where existing services consume them.

## Contracts

- Visible resident homes: exactly sixteen maximum.
- Neighbourhoods: Meadow Lane, Harbour Row, Woodland Rise, and Orchard End.
- Recognizability: silhouette, scale, material, and feedback must all pass.
- Starter/Cosy homes: a physical kitchen counter is available from first entry; the paid `KitchenCounter` catalog item remains a progression upgrade rather than the only way to make the room usable.
- Residential ambience: warm windows and chimney smoke bind to the assigned house prefab, remain seeded and budgeted, and are released when the home is rebuilt or vacated.
- Terrain: four authored elevation bands provide bounded, visible height variation for the four neighbourhoods; the seed composes dressing around those authored anchors rather than generating unbounded noise.
- Portal collectibles: Sugar Crystals and Moonlit Seeds are named authored prefabs with recognizable silhouettes, materials, physical-affordance metadata, and prompts; labels are supplemental.
- UI: compact normal-play HUD; raw telemetry only behind a Studio gate.
- Authority: client and art builders do not own economy, progression, privacy, trade, transport, portal, inventory, or saves.
- Compatibility: profile version 10 remains valid; no migration is introduced.
