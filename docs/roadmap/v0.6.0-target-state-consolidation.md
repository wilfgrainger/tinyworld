**Status:** active release candidate
**Purpose:** apply the complete repository-side Target-State Upgrade Blueprint in one release/PR.

v0.6.0 turns the strong v0.5.x vertical slice into a scalable life-sandbox foundation:

- profile schema v11 and explicit migrations;
- generic stacks/instances/furniture placements/outfits/discovery;
- 80-item home catalogue definition floor across eight categories;
- server-authoritative Home Store and physical furniture placement;
- reusable home interaction verbs;
- free character expression/wardrobe foundation;
- four authored impossible worlds;
- four ordinary-life activity definitions;
- 30+ keepsake definitions;
- lightweight ambient village characters;
- durable trade transaction journal while high-value trade remains disabled;
- RemoteGuard and onboarding hardening;
- DEV/LIVE DataStore separation;
- bounded product analytics taxonomy;
- responsive UI components and touch/controller placement;
- performance/accessibility/asset/safety contracts;
- StyLua/recursive compile CI;
- v0.6.0 traceable Rojo artifact.
