## Current visual direction

TinyWorld aims for **Brookhaven-level readability + Toca-style tactile warmth + Ready Player One-style wonder**, expressed as original TinyWorld design rather than copied IP.

Current hard rules include:

- no primitive character/ambient-creature fallback presented as finished art;
- no large always-on-top ordinary-world information walls;
- no telemetry/dashboard normal-play treatment;
- no slab-dominated hero buildings;
- no pasted bright-cyan ordinary window language;
- no naked Neon sphere practical lamps;
- village composition must not read as plots on one empty green plane;
- four neighbourhoods need visible environment identity;
- labels/metadata cannot rescue weak physical art;
- observed exact-candidate visual evidence is a release gate.
