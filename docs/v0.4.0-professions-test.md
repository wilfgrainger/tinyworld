# TinyWorld v0.4.0 profession expansion test

v0.4.0 preserves the Courier job and adds two transparent, fair identity
paths: Farmer for physical garden harvests and Designer for physical home
expression. It adds no item reward, paid gate, random reward, combat power, or
client-owned progression.

## Local verification

Run from the repository root:

```powershell
luau tests/run.luau
luau-analyze src/shared/*.luau tests/*.luau
$compiler = "C:\Users\wilf6\scoop\apps\luau\current\luau-compile.exe"
Get-ChildItem src/server -Filter *.luau | ForEach-Object { & $compiler $_.FullName > $null }
Get-ChildItem src/client -Filter *.luau | ForEach-Object { & $compiler $_.FullName > $null }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/verify-professions.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/verify-item-reward-contract.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/verify-physical-items.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/verify-roblox-materials.ps1
rojo build default.project.json -o .worktrees\tinyworld-v0.4.0.rbxlx
git diff --check
```

## Studio route

1. Start Play from the current Rojo-synced place. Confirm the HUD reads
   `TINYWORLD | v0.4.0`, shows `Careers: Courier ... Farmer ... Designer ...`,
   and still shows the v0.3 physical Item Chest contents.
2. Walk to the physical **PROFESSION BOARD** and use **View Professions**.
   Confirm the popup names Courier, Farmer, and Designer with levels and XP
   thresholds.
3. On an owned plot, let a physical carrot reach the labelled `CARROT READY`
   state and harvest it. Confirm the real carrot leaves the bed, the HUD bag
   increases, the Item Chest updates, and the popup says `Farmer XP +50`.
4. Use **HOME GALLERY** to acquire a concrete decoration. Confirm the visible
   furniture rebuilds and the popup says `Designer XP +50`. Use the physical
   home showcase plaque and confirm `Designer XP +25`.
5. Stop and rejoin. Confirm Courier, Farmer, Designer, the physical chest,
   garden state, home décor, and the existing profile values persist.
6. Stop again and inspect Output. A Rojo disconnect or the known Studio
   DataStore queue/session warning is a separate test dependency; any red
   source/runtime exception is a failure.
