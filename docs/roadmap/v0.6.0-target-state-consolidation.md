# v0.6.0 Target-State Consolidation

**Status:** active release candidate  
**Purpose:** apply the complete repository-side Target-State Upgrade Blueprint in one release/PR.

## Scope reconciliation

The canonical v1 target-state release train originally names v0.6.0 **Home Life Foundation** because home life is the primary player-visible product outcome of this release. On 9 August 2026 the repository owner explicitly approved implementing the **entire repository-side Target-State Upgrade Blueprint as one v0.6.0 PR**. Therefore the active delivery scope is **v0.6.0 Target-State Consolidation**, with Home Life Foundation nested inside it as the principal player-facing slice rather than a competing release definition.

This explicit decision supersedes the older v0.5.x roadmap assignment that had deferred a Fair Cosmetic Economy slice to v0.6.0. Cosmetic expression remains no-pay-to-win and is included only as part of the broader character/home expression foundation described here.

For v0.6.0 sequencing, this document and `docs/releases/v0.6.0/acceptance.md` are authoritative. `docs/product/target-state-v1.md` remains authoritative for the long-term product destination and player-visible release intent.
