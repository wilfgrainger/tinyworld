# Issue-First Workflow Acceptance

Controlling issue: #16

The repository workflow change is acceptable when:

- `AGENTS.md` tells contributors to locate/create and read the controlling issue before implementation.
- `docs/DEVELOPMENT_WORKFLOW.md` defines the lifecycle from design through DEV publication and human acceptance.
- release and work-item issue templates capture design, scope, dependencies and acceptance.
- the pull request template requires a controlling issue and exact-head verification evidence.
- secrets are explicitly prohibited from issues, docs and PR text.
- visual/player-facing work is not considered complete from CI alone.
- the existing single free-only CI and DEV publishing architecture is not modified by the governance change.
- ART R7 uses the model end-to-end via Issues #17-#22.
