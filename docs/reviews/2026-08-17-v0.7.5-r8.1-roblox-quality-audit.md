## Source-level visual review

The R8.1 source no longer treats activity mechanics as permission to build entire permanent locations from runtime debug geometry.

- Pip now uses an authored three-bed garden composition with edging and garden props.
- Finn now uses an authored dock with deck, walkway, rails, tackle bench/crate and explicit fishing/NPC anchors.
- Milo now uses an authored repair station with workbench, backboard, three stateful repair boards and workshop props.
- Skye's outer target is an authored buoy with body, banding, mast, crossbar and beacon.
- Existing authored MarketHouse, GardenShed, Workshop and HarbourHut remain the civic destination family.
- NPC and activity positions are resolved from named destination anchors rather than the retired perimeter coordinate table.

This is a source-quality PASS, not a rendered visual PASS.

## Visual failure conditions

Do not approve rendered R8.1 if evidence shows any of the following:

- overlapping legacy and R8 scenery;
- duplicate activity destinations;
- primitive hero fallback boxes;
- giant empty grass plane dominating ordinary camera views;
- checkerboard/purple corruption;
- grass flicker or z-fighting;
- avatar sinking or unsafe shoreline transitions;
- floating, exploded or intersecting architecture;
- unreachable or buried prompts;
- NPCs inside scenery or visibly off the ground;
- activity areas that still read as debug stations;
- incoherent scale/material language between adjacent hero areas;
- excessive mobile HUD obstruction;
- runtime errors in Developer Console during the tested flows.
