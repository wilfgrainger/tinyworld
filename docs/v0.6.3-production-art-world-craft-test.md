## 9. Performance/runtime smoke

Record:

- exact source SHA and `.rbxlx` hash;
- Output critical errors;
- useful-spawn time;
- sustained FPS on agreed phone/device profile;
- memory;
- obvious collision/traversal regressions around new decoration.

Targets remain >=30 FPS sustained mobile, <=500 MB memory and <=15 seconds useful spawn unless a release record explicitly changes them.

## Scoring rule

For each required view record PASS/FAIL for:

1. architecture/silhouette;
2. material/colour hierarchy;
3. lighting;
4. landscape/composition;
5. labels-off comprehension;
6. placeholder/prototype reading;
7. clipping/occlusion.

If a required hero view still reads as prototype/test geometry, the release fails visually regardless of green CI.
