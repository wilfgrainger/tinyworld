## Current release

[v0.6.3 Production Art & World Craft](v0.6.3-production-art-world-craft.md) is active.

It is a deliberately feature-light corrective release driven by observed v0.6.2 Studio screenshots. The gameplay foundation is preserved while homes, civic destinations, lighting, landscaping and neighbourhood composition receive the strongest craft pass yet.

The product north star remains [TinyWorld v1 Target State](../product/target-state-v1.md).

## v0.6.3 focus

- remove slab-dominated hero architecture;
- replace pasted cyan window treatment with framed/recessed window language;
- replace naked practical-light spheres with believable fixtures;
- strengthen home/civic entrances, porches, roofs, foundations, trim and material hierarchy;
- recompose civic approaches and neighbourhood landscape clusters;
- remove surviving Part-built ambient birds/butterflies;
- raise starter-home interior craft without changing home gameplay;
- preserve the compact HUD and normal Roblox avatar;
- preserve schema 11 and all v0.6.2 security/persistence/trade/gameplay authority;
- require comparable exact-candidate Studio screenshots before visual success is claimed.

## Reserved v0.7.0

v0.7.0 is reserved for the family/girls review. Do not populate it from assumptions before that review is supplied.

## Release discipline

- player-facing PRs may be source/build green while Studio/device evidence is NOT RUN;
- NOT RUN/FAIL visual rows are never converted to PASS from source inspection;
- generated concept art is reference-only, never release evidence;
- FAIL is useful evidence and creates bounded corrective work;
- source/CI does not substitute for observed visual quality;
- future impossible-world work inherits the v0.6.3 ordinary-world art baseline rather than using fantasy glow to hide a weak village;
- v0.9.0 prioritises measured production evidence;
- v1.0.0 freezes major system scope and focuses on launch polish/safety/evidence.

## Deferred external gates

The repository deliberately contains no production credentials, fake IDs or automatic LIVE publishing. DEV/LIVE configuration and same-artifact promotion occur only after explicit approval and recorded runtime/device evidence.
