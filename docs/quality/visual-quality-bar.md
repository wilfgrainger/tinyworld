# Visual quality bar

## Recognizability

Every key player-facing object must pass all four checks with its label hidden:

1. **Silhouette:** can a player identify the category from shape?
2. **Scale:** does it read correctly beside the avatar and nearby props?
3. **Material:** do colour and surface imply its identity and use?
4. **Feedback:** does interaction create visible, audible, or motion feedback?

A missing dimension fails the object contract. Text, prompt labels, neon rings, and arbitrary colour coding cannot compensate.

## Village bar

- The centre is not a symmetric grid of generic boxes.
- Each civic destination has a distinct roofline, facade, props, and approach.
- Four residential neighbourhoods are distinguishable through terrain, planting, paths, clutter, and outlook.
- Landmarks remain visible above roofs and routes remain traversable.
- Dressing is deterministic, bounded, and safe for mobile readability.

## Home bar

The hero starter/Cosy home visibly contains bedroom, kitchen, living, bathroom, storage, and garden life. Interactions attach to recognizable objects and provide bounded state feedback. Higher tiers preserve their progression silhouettes.

## UI bar

Normal play shows only coins, level progress, one current task, journal access, short toasts, and contextual prompts. Raw replicated fields are Studio-only. Friendly copy explains player intent rather than database structure.

## Evidence

Source guards can prove names and boundaries. A fresh Studio screenshot with labels hidden and a play route are required to prove composition, recognizability, and feedback.

## v0.5.2 premium-feel quality gate

This is a pass/fail production-quality gate, not monetisation. “Premium” is accepted only as the following observable bundle:

| Check | Pass | Fail |
| --- | --- | --- |
| Authored silhouettes | Required homes, destinations, vehicles, and touched objects read from shape with labels off. | A generic block, sign, or colour must explain the object. |
| Quality materials | Contextual wood, brick, slate, glass, fabric, metal, water, and foliage reinforce object identity. | Arbitrary colour coding or anonymous material treatment dominates a primary object. |
| Composed lighting | Daylight, shadows, warm windows, and restrained glow preserve hierarchy and mobile contrast. | Flat exposure, blown neon, or darkness hides routes and silhouettes. |
| Tactile feedback | Input produces bounded motion, light, object state, sound, or a short toast. | Only text or telemetry changes. |
| Restrained UI | The compact HUD, contextual prompts, journal, and short toasts leave the world dominant. | Telemetry walls or raw replicated fields dominate normal play. |
| No arbitrary coloured cubes | Every player-facing object has a visible art and physical-affordance role. | A coloured cube is the verb, destination, or feedback. |
| Labels-off child-recognition test | The exact Studio route records the required uncoached recognitions. | Any required category needs labels, telemetry, or coaching. |

One failed row fails the v0.5.2 premium-feel quality gate.
